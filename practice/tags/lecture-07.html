Problem #71

Tags: lecture-07, quiz-04, pca

Let \(\vec{x}^{(1)}\) and \(\vec{x}^{(2)}\) be two points in a data set \(\mathcal{X}\) of 100 points in \(d\) dimensions. Suppose PCA is performed, but dimensionality is not reduced; that is, each point \(\vec{x}^{(i)}\) is transformed to the vector \(\vec{z}^{(i)} = U \vec{x}^{(i)}\), where \(U\) is a matrix whose \(d\) rows are the (orthonormal) eigenvectors of the data covariance matrix.

True or False: \(\|\vec{x}^{(1)} - \vec{x}^{(2)}\| = \|\vec{z}^{(1)} - \vec{z}^{(2)}\|\). That is, the distance between \(\vec{z}^{(1)}\) and \(\vec{z}^{(2)}\) in the new data set is necessarily the same as the distance between their corresponding points in the original data set.

Solution

True.

Since \(U\) is an orthogonal matrix (its rows are orthonormal eigenvectors), it preserves distances. For any vector \(\vec{v}\):

\[\|U\vec{v}\|^2 = (U\vec{v})^T(U\vec{v}) = \vec{v}^T U^T U \vec{v} = \vec{v}^T \vec{v} = \|\vec{v}\|^2 \]

Therefore:

\[\|\vec{z}^{(1)} - \vec{z}^{(2)}\| = \|U\vec{x}^{(1)} - U\vec{x}^{(2)}\| = \|U(\vec{x}^{(1)} - \vec{x}^{(2)})\| = \|\vec{x}^{(1)} - \vec{x}^{(2)}\|\]
